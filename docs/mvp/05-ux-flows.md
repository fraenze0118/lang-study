## 1. 首次启动（选语种 → 自选起点）

```
启动 → 选学习语种（日语 / 韩语）
     → 该语种的起点档位（5 档，随语种变化）
     → 写入 user_languages + app_preferences.active_language_id → 进入对话主页
```

- **不做逐题测评**（原设计的 10~15 题自适应测试已废弃）：起点由用户自己定，学得不对再用难度反馈调整。
- 起点档位来自 `LanguageProfile.startingPoints`，因此文案与等级标签随语种变化：
  - 日语：完全零基础 / 认得假名 / 学过一阵子 / 能日常交流 / 备考 JLPT N2·N1（等级 N5..N1）
  - 韩语：完全零基础 / 认得谚文 / 学过一阵子 / 能日常交流 / 备考 TOPIK 5·6 级（等级 TOPIK1..6）
- 选「完全零基础」→ 该语种最低等级，且**不跳过字母入门单元**（日语五十音 / 韩语谚音）。
- 选其他起点 → 对应等级，并在 `user_languages.skip_script_units=1`，学习推荐时跳过入门单元。
- 已设定过（`assessment_done=1`）→ 直接进对话主页。
- 起点之后仍可在「设置」里随时改；也可在那里**切换语种或再加一门**。

> 「认得假名」不代表「认得谚文」，所以该偏好**按语种独立**存储。

## 2. 对话入口流（核心）

```
对话主页（AI 问候 + 状态提示：水平/待复习 N 个）
  ├─ 「帮我安排一批」→ AI 推荐内容预览 → 确认 → 学习页
  ├─ 「我想学流行词」→ AI 生成内容预览 → 确认 → 学习页
  ├─ 「我要复习」   → 跳知识库复习
  ├─ 「太简单了」   → 调整难度（AI 回复确认）
  └─ 自由提问      → 答疑
```

- 内容在对话里以**预览卡片**呈现（条目列表 + 推荐理由），用户点「开始学习」才进入学习页。
- 学习页是专门界面（非聊天流），学完自动返回对话。

## 3. 学习会话流

```
学习页（一屏一步的步骤机）
  intro（本批概览）
  → 每个条目：闪卡（surface + 发音标注）→ 显示释义 / 或 AI 讲解 + 例句
  → 语法点：结构拆解 + 例句 + 易错提示
  → 练习（选择/填空/翻译）→ 提交即判分 → 绿/红反馈条 + 讲解
  → 结算页（正确率 / 最高连击 / 获得经验 / 今日目标 / 连续天数）
  → 落库 + 进复习 → 返回对话
```

- 顶部贯穿式进度条取自「已完成步数 / 总步数」。
- 连击跨题目累计，答错归零；连击 ≥3 有经验加成。
- **只有走到结算页才提交**；中途退出会二次确认且不计入。
- 朗读语言与发音标注名称随当前语种。

- 学习结束后对话里出现一句总结（"已学 X 词，已加入复习队列"）——这就是进度变化。

## 4. 知识库 / 复习流

```
知识库页
  ├─ 单词库 / 语法库（tab 切换）
  ├─ 搜索、按掌握度/等级筛选
  ├─ 条目详情（+「问 AI」）
  └─ 「开始复习」→ 抽取到期内容 → 复习页
                             └─ 闪卡 + 四档评分（Again/Hard/Good/Easy）
```

## 5. 难度反馈流

```
学习中/学习后 → 反馈「太简单 / 刚好 / 太难」
  → 写入 difficulty_feedback
  → difficulty_bias 调整（越界则升降 level_code）
  → 下次 AI 生成内容难度变化
```

## 6. 页面导航结构

```
对话主页（初始）
  ├─ 学习页
  ├─ 知识库页
  │    └─ 条目详情 → 问 AI（对话）
  │    └─ 复习页
  └─ 设置页
```

## 7. 空状态与异常

| 场景 | 处理 |
|---|---|
| 无到期复习 | "当前没有需要复习的内容" |
| AI 生成失败 | 重试 + 降级到大纲内容 |
| 意图不明 | AI 追问澄清 |
| 离线 | 知识库/复习可用；AI 功能提示联网 |
