# Part 1 · MRD（市场需求）

## 1.1 背景与问题

| # | 痛点 | 旧版局限 |
|---|---|---|
| 1 | 有基础的学习者不想从零开始，也不想被固定大纲牵着走 | 旧版默认零基础、按 N5 大纲顺序推进 |
| 2 | 想学的内容是灵活的（如"最新流行词"），不是固定教材 | 旧版只能学预设大纲条目 |
| 3 | 学过就忘、学了没体系感、复习无抓手 | 学习与复习割裂，缺乏知识库沉淀 |

## 1.2 目标用户

- **核心用户（MVP）**：中文母语、**有一定日语基础**（非零基础）、希望按需灵活学习的自学者。
- 水平范围：零基础至高级（JLPT N5–N1），**动态评估**。

## 1.3 价值主张

> 一个「对话式发起、按需学习、随时复习」的 AI 日语学习助手：打开 App，跟 AI 说这次想学什么，AI 按你的动态水平和知识库提议内容，学完自动沉淀进知识库并进入复习队列。

**核心差异化**：**用户主导 + AI 引导**。不是"AI 每天喂你内容"，也不是"漫无目的地跟 AI 聊天"——而是 AI 理解你的水平与知识库，在你主动发起时给出恰到好处的学习内容。

## 1.4 目标与成功标准（MVP）

| 目标 | 度量 |
|---|---|
| 学习闭环成立 | 对话发起 → 学习 → 知识库沉淀 → 可复习 |
| 个性化 | 自选起点 + 学习中反馈能影响后续内容难度 |
| 灵活内容 | 既能学大纲内容，也能学 AI 生成的新内容（如流行词） |
| 可用体验 | UI 有设计感，流程自然不毛坯 |

# Part 2 · PRD（产品需求）

## 2.1 产品定位与核心决策

| 维度 | 决定 |
|---|---|
| 语言 / 释义 | **多语种（日语 + 韩语）**，中文释义；同一时间只学一个语种，数据按语种隔离 |
| 平台 | 手机 App（iOS/Android），React Native (Expo) + TypeScript |
| 交互模型 | **对话式入口**：用户发起，AI 引导 |
| 学习界面 | 对话只做决策，学习用**沉浸式专门界面** |
| 水平模型 | **动态画像**：启动时自选起点 + 学习中反馈持续调整；水平**按语种独立** |
| 内容来源 | **大纲 + AI 自由生成**，都沉淀进知识库 |
| 复习 | 放在**知识库页面**下，抽到期内容复习（FSRS） |
| UI | 温暖游戏化 |

## 2.2 信息架构

| 页面 | 职责 |
|---|---|
| **对话主页** | 唯一入口：定内容、答疑、反馈难度 |
| **学习页** | 沉浸式：卡片 → 讲解 → 练习 |
| **知识库** | 单词库 / 语法库浏览 + 掌握度 + **复习入口** |
| **设置/画像** | 水平、目标（弱化） |

## 2.3 功能需求

### 2.3.1 对话式入口（AI Agent）
- 进入 App 即对话主页，AI 问候并提示当前状态（大致水平、待复习数）。
- 识别四类意图：
  1. **学新**：AI 推荐（"帮我安排一批"）/ 自定义主题（"我想学最新的流行词"）
  2. **复习**：跳转知识库复习
  3. **答疑**：自由提问
  4. **难度反馈**："太简单 / 太难了" → 调整画像
- 学习内容在对话里**预览确认**后，切到学习页执行。

### 2.3.2 学习会话
- AI 按「画像（水平 + 难度偏移）+ 知识库已学」生成/选取一批条目（词 + 语法）。
- 学习页：闪卡 → AI 讲解/例句 → 练习。
- 学完：条目写入知识库、进入 FSRS 复习队列（这是"进度变化"的来源）。

### 2.3.3 知识库
- 分**单词库 / 语法库**，每条含：假名、释义、例句、掌握度、来源（大纲/AI）。
- 支持搜索、按掌握度/等级筛选。
- **复习入口**：一键抽取到期内容开始复习。

### 2.3.4 复习
- 基于 FSRS，四档评分（Again/Hard/Good/Easy）。
- 抽取策略：优先到期最久 / 最不稳的内容。

### 2.3.5 水平设定 + 动态难度
- **初始水平：用户自选**，不做逐题测评。给出 5 个起点（完全零基础 / 认得假名 / 学过一阵子 / 能日常交流 / 备考 N2·N1），选「完全零基础」就从五十音（平假名、片假名）开始教；选其他起点则跳过五十音，直接从对应等级的内容开始。
- **持续调整**：学习中/后反馈"太简单/刚好/太难"→ 更新 `difficulty_bias`（累积到阈值则升降 `level_code`）→ 影响后续内容难度。用户反馈优先，自选起点只是起点。

### 2.3.6 AI 答疑
- 对任意知识库条目或自由内容提问，AI 带上下文（条目 + 水平 + 已学摘要）回答。

## 2.4 非功能需求

| 类别 | 要求 |
|---|---|
| 离线 | 知识库/复习完全本地；仅 AI 功能需联网 |
| AI 质量 | 生成条目的假名/释义需校验；超纲内容提示 |
| 性能 | 内容生成 < 8s，对话响应 < 5s |
| UI | 温暖游戏化设计系统，统一组件与动效 |

## 2.5 MVP 范围

**做（In）**：**多语种（日语 + 韩语，可切换）**、对话入口、学习会话（AI 推荐 + 自定义）、知识库（浏览 + 复习入口）、FSRS 复习、自选起点 + 动态难度、AI 答疑、游戏化（经验/连击/每日目标/连续天数）、基础数据备份。

**不做（Out）**：语音对话、账号多设备同步、游戏化完整成就体系、内容版权处理、正式商业化。

## 2.6 验收标准（MVP）

1. 打开 App → 选语种 → 对话 → 定内容 → 沉浸式学习 → 知识库可见 → 可复习，闭环成立。
2. 自选起点能定位大致 JLPT / TOPIK 起点；"太简单/太难"反馈能影响后续内容。
3. 能学 AI 生成的新内容（如流行词），并正确落库、进复习。
4. 知识库可浏览、搜索、看掌握度；复习能抽取到期内容。
5. 切换语种后，知识库/复习/统计/对话只显示当前语种；每日经验与连续天数保持连续。
6. 升级安装不丢失既有学习数据。
5. UI 有明显设计感，非毛坯。
