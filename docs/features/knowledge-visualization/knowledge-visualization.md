# 知识库可视化分类 功能设计

| 项 | 内容 |
|---|---|
| 文档版本 | v1.0 |
| 状态 | 已评审并实现 |
| 关联 | MRD-PRD.md、02-data-model.md、KnowledgeScreen |
| 目标 | 让已学内容「有结构、可浏览、有视觉锚点」，解决词多后"乱"的问题 |

## 1. 背景与问题

当前知识库（`KnowledgeScreen`）是：**单词/语法 tab + 搜索 + 一条条平铺列表**（surface/reading/meaning/掌握度文字）。

问题：
- 词一多就是一大串，**没有分组、没有层次**，视觉上"乱"。
- 用户无法快速感知「我学了哪些主题」「哪些还没掌握」「N4 的词有哪些」。
- 缺少"整体感"——不知道自己学习的分布情况。

## 2. 目标

1. **一眼看清整体**：学了多少、掌握多少、分布如何。
2. **多维度归类浏览**：按主题 / 等级 / 词性 / 掌握度，快速切换查看。
3. **可视化**：用颜色、分组、进度条，让"已学内容"有视觉锚点，不再是纯文字。

## 3. 可用的分类维度（数据基础）

已学条目 `items` 已具备这些字段，可作为分类依据：

| 维度 | 字段 | 取值 | 说明 |
|---|---|---|---|
| 掌握度 | `user_item_states.mastery_state` | new / learning / mastered | 学习进度 |
| 等级 | `items.level_code` | N5~N1 | 难度等级 |
| 主题 | `items.unit_id` → `units.title` | 问候/日常物品/数字/动作… | AI 生成词无单元 |
| 词性 | `items.pos` | 名词/动词/形容词/助词… | 语法词性 |
| 来源 | `items.source` | syllabus / ai | 大纲 vs AI 生成 |

## 4. 设计方案

### 4.1 知识库页改造后的信息架构

```
知识库页
├─ 顶部：统计概览
│     · 已学 X · 已掌握 Y · 待复习 Z（三个大数字卡片）
│     · 掌握度分布条（一条三段横向彩条：灰=新学 / 橙=学习中 / 绿=已掌握）
├─ 维度切换 chips：〔按主题〕〔按等级〕〔按词性〕〔按掌握度〕
├─ 分组折叠列表（SectionList，按所选维度分组）
│     └─ 每组：组头（名称 + 数量 + 小进度）→ 点开见词条
├─ 词条网格视图（可选，一键切换）：彩色词条胶囊
└─ 搜索框（保留，过滤当前列表）
```

### 4.2 可视化细节

**① 颜色编码（贯穿全页的视觉锚点）**
| 掌握度 | 颜色 |
|---|---|
| 新学 new | 灰 `#9ca3af` |
| 学习中 learning | 橙 `#ea580c` |
| 已掌握 mastered | 绿 `#16a34a` |

- 每个词条前加一个**颜色圆点**标识掌握度。
- 网格视图中，整个词条胶囊的背景/边框用掌握度颜色。

**② 掌握度分布条**
- 一条横向三段条，三段长度按比例 = 新学 : 学习中 : 已掌握。
- 纯 RN `View` 实现（不引入图表库）。

**③ 分组头**
- 左侧：分类名；右侧：`数量` + 一个迷你进度（如"已掌握 3/10"）。

### 4.3 交互

- 点 chips 切换维度 → 列表按新维度重新分组。
- 点组头 → 折叠/展开该组。
- 点词条 → 进条目详情（已有 `ItemDetail`）。
- 搜索 → 过滤所有组（已有，保留）。
- 「列表 / 网格」切换按钮（可选）。

## 5. 技术方案

- **数据**：`getKnowledgeItems` 已返回 `type/level/mastery/surface/meaning`；需补充 `unitTitle`、`pos`（数据已有，查询补字段即可）。
- **分组逻辑**：一个纯函数 `groupItems(items, dimension): Group[]`，`dimension ∈ {mastery, level, theme, pos}`。
- **组件**：
  - `StatsOverview`（数字 + 分布条）
  - `DimensionTabs`（chips）
  - `GroupedList`（SectionList）
  - `WordGrid`（可选，彩色胶囊）
- **不引入图表库**：分布条、进度都用纯 RN View/Text 实现，轻量。

## 7. 验收标准

1. 知识库不再是纯平铺，能按 4 个维度分组浏览。
2. 顶部能看到整体统计 + 掌握度分布。
3. 每个词条有掌握度颜色标识，一眼可辨。
4. 搜索、点击进详情等现有能力不退化。
