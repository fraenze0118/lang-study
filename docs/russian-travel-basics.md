# 俄罗斯旅行俄语速成手册

> 目标：**不学语法体系、不背单词表，只解决"到了俄罗斯怎么把事办成"**。
> 适用：零基础 / 只会 26 个英文字母的旅行者。预计投入 6～8 小时（每天 40 分钟 × 7 天）即可覆盖全部核心场景。

| 项 | 内容 |
|---|---|
| 版本 | v1.0 |
| 词汇量 | 约 300 词 / 150 句 |
| 核心原则 | **会用 > 说对**。语法错误、口音重，俄罗斯人都能听懂 |
| 配套 | 手机装 Yandex Maps + Yandex Translate（Google 在俄境内基本不可用） |

## 0. 怎么用这份文档

### 0.1 三条铁律

1. **先说"对不起 + 我不懂俄语"，再说英语。** 直接飙英语容易碰钉子，先道歉成功率翻倍。
   `Извините, я не говорю по-русски. Вы говорите по-английски?`
2. **指着说永远比说着说有效。** 地名、菜单、地址一律用手机放大给对方看，配合"Это?（这个吗）"。
3. **听不懂时不要重复原句，要换更短的词。** 见 §2.3 救场三步。

### 0.2 发音标注说明

每句给三行，**优先看第 2 行（拉丁转写）**，第 3 行中文谐音只是应急记忆法：

- **大写音节 = 重音**（俄语重音不可预测，必须单独记，标错会被听成别的词）
- 中文谐音**只能当拐棍**：俄语的 `ы`、卷舌 `р`、软辅音在汉语里没有对应音
- 说话时**放松、别拖长**，俄语语速快、节奏平，重音前的 `о` 一律念成 `a`（Москва → Mask-VA）

## 1. 第一关：认字母（约 90 分钟）

去俄罗斯最实用的一件事是**看懂招牌和标识**，否则连厕所和出口都找不到。西里尔字母 33 个，但其中一大批和拉丁字母同形同音，真正要背的只有十几对"假朋友"。

### 1.1 不用背的（和英文几乎一样）

| 字母 | 音 | 字母 | 音 |
|---|---|---|---|
| А а | a | Р р | **卷舌 r**（不是 p！） |
| К к | k | С с | s（不是 c） |
| М м | m | Т т | t |
| О о | o | У у | u |

> 看到 `РЕСТОРАН` 就是 restaurant，`МЕТРО` 就是 metro，`ТАКСИ` 就是 taxi。

### 1.2 必须背的（13 个坑）

| 字母 | 实际发音 | 谐音 | 例词 |
|---|---|---|---|
| В в | v | 维 | Вода（水） |
| Н н | **n**（不是 h） | 恩 | Нет（不） |
| Р р | **卷舌 r**（不是 p） | 儿 | Рубль（卢布） |
| С с | **s**（不是 k） | 斯 | Сок（果汁） |
| У у | **u**（不是 y） | 乌 | Утро（早晨） |
| Х х | 类似"喝" | 赫 | Хлеб（面包） |
| Ц ц | ts | 次 | Центр（中心） |
| Ч ч | ch | 奇 | Чай（茶） |
| Ш ш | sh（硬） | 什 | Шоколад（巧克力） |
| Щ щ | shch（软） | 嘘 | Щи（菜汤） |
| Ж ж | 类似"日" | 日 | Женский（女） |
| Ы ы | 舌后缩的"衣" | 厄衣 | Сыр（奶酪） |
| Э э | e（不是 ye） | 埃 | Это（这） |

### 1.3 软音记号与几个特殊字母

| 字母 | 说明 |
|---|---|
| Е е | ye（"耶"）——Есть（有） |
| Ё ё | yo（"哟"）——Лёд（冰） |
| Ю ю | yu（"尤"）——Юг（南） |
| Я я | ya（"亚"）——Я（我） |
| Й й | 短 i，作尾音——Чай（茶，念"恰伊"） |
| Ь ь | **不发音**，只把前一个辅音变"软"（舌尖抬高）——Соль（盐，念 solʲ） |
| Ъ ъ | 不发音，硬音符号，只隔音 |

### 1.4 三条读法规则（知道就能读得像样）

1. **非重音的 о 读成 a**：Москва → Mask-VA，Хорошо → kha-ra-SHO
2. **词尾浊辅音清化**：друг → "drook"，хлеб → "khlyep"，Петербург → "Peter-burk"
3. **-его / -ого 里的 г 读 v**：Сегодня → si-VOD-nya，Ничего → ni-che-VO

### 1.5 一眼认出的外来词（白送的词汇量）

`ресторан` 餐厅、`кафе` 咖啡馆、`отель` 酒店、`такси` 出租车、`метро` 地铁、`аэропорт` 机场、`паспорт` 护照、`виза` 签证、`банк` 银行、`интернет` 网络、`телефон` 电话、`аптека` 药店、`музей` 博物馆、`театр` 剧院、`балет` 芭蕾、`пицца` 披萨、`шоколад` 巧克力、`кофе` 咖啡、`салат` 沙拉、`суп` 汤、`бизнес-центр` 商务中心、`супермаркет` 超市、`таможня` 海关

### 2.3 听不懂时的救场三步（重要）

1. **亮手机**：打开 Yandex Translate，选"俄→中"，让对方**说给手机听**
2. **指句子**：把本手册里的句子给对方看，让他指"Да/Нет"
3. **换场景词**：不要重复原句，改问 `Где?（哪里）` `Сколько?（多少）` `Можно?（可以吗）` 这类单词

### 2.4 三个万能句型（套用能造无数句）

| 句型 | 意思 | 例 |
|---|---|---|
| **Мне нужен / нужна / нужно ___ ** | 我需要 ___ | Мне нужен врач（我需要医生） |
| **У меня есть ___ ** | 我有 ___ | У меня есть бронь（我有预订） |
| **Где ___ ?** | ___ 在哪里？ | Где туалет?（厕所在哪） |
| **Можно ___ ?** | 可以 ___ 吗？ | Можно картой?（可以刷卡吗） |
| **Сколько стоит ___ ?** | ___ 多少钱？ | Сколько стоит билет? |

> `нужен / нужна / нужно` 按后面名词的性别选：阳性用 нужен（врач、такси 不算），阴性用 нужна（вода），中性/外来词用 нужно（такси、меню）。**说错也没关系，对方能懂。**

## 6. 语法只学这 6 条

不用买语法书，旅行场景只需要这几条：

1. **现在时没有"是"**：`Я турист` = 我是游客。别找 am/is/are，俄语里现在时直接省略。
2. **你 vs 您**：对陌生人、店员、警察一律用 **вы**（维）；只有对朋友、小孩用 **ты**。用错"你"会显得没礼貌。
3. **否定只要一个 не**，放在动词前：`Я не понимаю`（我不明白）。不存在 don't/doesn't 的变化。
4. **疑问句不用改语序**，只把句尾语调上扬：`Вы говорите по-английски?`（升调）＝您会说英语吗？
5. **"有"用 У меня есть**：`У меня есть бронь`（我有预订）。直译是"在我这里有……"。
6. **"需要"按性别变**：нужен（阳）/ нужна（阴）/ нужно（中）。记不住就全用 **нужно**，对方一定懂。

> 附加一条文化规则：**俄罗斯人公共场合不随便笑**。收银员板着脸不是讨厌你，是当地习惯。你主动说一句 `Спасибо` 加上微笑，气氛立刻软化。
